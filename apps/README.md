# Job-Forge Web Application

Milestone 1.1: Project Setup & Infrastructure ✅

## Quick Start

### Prerequisites
- Docker & Docker Compose
- Git

### Getting Started

1. **Start all services**:
   ```bash
   docker-compose up
   ```

2. **Access the services**:
   - Frontend: http://localhost:5173
   - Backend API: http://localhost:8000
   - API Health Check: http://localhost:8000/api/health
   - API Docs: http://localhost:8000/docs (auto-generated by FastAPI)
   - MongoDB: mongodb://localhost:27017
   - Mongo Express (DB UI): http://localhost:8081

### Development

#### Hot-Reload
Both frontend and backend have hot-reload enabled:
- **Frontend**: Edit files in `apps/web/src/` and see instant updates
- **Backend**: Edit files in `apps/api/app/` and Uvicorn will auto-restart

#### Stopping Services
```bash
docker-compose down
```

#### Rebuilding After Dependency Changes
```bash
docker-compose build
docker-compose up
```

#### Viewing Logs
```bash
# All services
docker-compose logs -f

# Specific service
docker-compose logs -f web
docker-compose logs -f api
docker-compose logs -f mongodb
```

## Tech Stack

### Frontend
- **React 19** with TypeScript
- **Vite 8** - Fast build tool with HMR
- **Tailwind CSS 4** - Utility-first CSS framework
- **Node.js 24** - JavaScript runtime

### Backend
- **FastAPI 0.138** - Modern Python web framework
- **Uvicorn** - ASGI server with auto-reload
- **Motor 3.7** - Async MongoDB driver
- **Beanie 2.1** - MongoDB ODM
- **Pydantic 2.13** - Data validation
- **Poetry 2.4** - Python dependency management
- **Python 3.13** - Programming language

### Infrastructure
- **Docker & Docker Compose** - Containerization
- **MongoDB 8** - NoSQL database
- **Mongo Express** - Database web UI

## Environment Variables

### Frontend (`apps/web/.env`)
```bash

```

### Backend (`apps/api/.env`)
```bash

MONGODB_DB_NAME=job_forge
DEBUG=true
ENVIRONMENT=development
```

See `.env.example` files for complete configuration options.

## Troubleshooting

### Port Already in Use
If ports 5173, 8000, 27017, or 8081 are already in use, stop the conflicting services or modify the ports in `docker-compose.yml`.

### Docker Build Issues
```bash
# Clean rebuild
docker-compose down -v
docker-compose build --no-cache
docker-compose up
```

### Permission Issues
On Linux, if you encounter permission errors with volume mounts, ensure Docker has proper permissions or run with appropriate user mapping.
